AgentHub 版本更新日志
================================================================

v1.15 (versionCode 20)
----------------------------------------------------------------
[改进] 错误处理：订阅相关错误不重试，提供更清晰的错误提示
[新增] 订阅错误解决指南：帮助用户解决 CodingPlan 订阅问题

v1.14 (versionCode 19)
----------------------------------------------------------------
[修复] 对话混乱问题：添加会话键过滤，防止不同对话的消息交叉
[修复] 上下文遗忘问题：发送历史对话上下文，保持长对话的连贯性
[新增] 配置导入功能：设置页「配置持久化」模块新增导入按钮，
  可从外部文件导入配置

v1.12 (versionCode 17)
----------------------------------------------------------------
[新增] 上传文件功能
  - 输入栏新增附件按钮（📎），调用系统文件选择器，可选任意类型文件
  - 文本类（.txt/.md/.json/.kt/.py 等扩展名或 text/* MIME）
    直接嵌入文件内容到消息，便于 agent 阅读
  - 二进制类文件转 base64 data URI 嵌入
  - 超过 256KB 的文件仅记录元数据（文件名/大小/类型），
    防止消息撑爆；agent 可通过工具读取
  - 发送前可预览文件标签（横向滚动）并移除
  - 消息气泡内显示文件标签，持久化到本地，重启后保留
  - 修改提问重发时保留原消息附带的文件
[新增] 配置持久化到外部存储（卸载不丢失）
  - 设置页新增「配置持久化」模块
  - 授权后配置同时保存到 /sdcard/AgentHub/config.json
  - 卸载重装后自动恢复连接配置，无需重新填写
  - AndroidManifest 加 hasFragileUserData="true"，
    让系统卸载时询问是否保留应用数据
  - 加 MANAGE_EXTERNAL_STORAGE 权限（Android 11+）
    和 WRITE_EXTERNAL_STORAGE（Android 10 及以下）
[修复] 等待回复超时（超过 300 秒）频繁出现
  - CHAT_TIMEOUT_MS 从 5 分钟放宽到 10 分钟
  - 自动重连次数 2 → 3
  - 新增静默断连看门狗：120 秒无任何事件即主动关闭
    socket 触发重连（防止 NAT/WiFi 省电导致的"看似在线
    实则断开"，OkHttp 未感知 onFailure 的场景）
  - 重连复用 idempotencyKey，服务端不会重复执行

v1.10 (versionCode 15)
----------------------------------------------------------------
[新增] 发送图片功能
  - 输入框左侧图片按钮，调用系统相册选图，最长边压缩至
    1024px、JPEG 80% 后转 base64 附加到消息
  - 发送前支持预览（缩略图）与移除
  - 消息气泡内按 1~2 列缩略渲染用户图片，持久化到本地
[新增] Agent 回复终止功能
  - 回复进行中时发送按钮切换为红色「停止」图标
  - 点击后取消当前聊天协程，助手消息末尾标记「已终止」
[新增] 提问修改功能
  - 每条用户消息左侧新增「编辑」图标，仅在对话空闲时可用
  - 弹窗修改后，截断该条之后的所有消息（含旧回复）并重新生成
  - 修改时保留原消息附带的图片
[改进] 对话标题自动总结
  - 不再基于首轮助手回复首行
  - 改为优先取用户首个提问的前 15 字（贴合用户预期、无歧义）
  - 无用户提问时再拼接全部对话内容抽取
[改进] 底部状态栏（模型/token/缓存）
  - 只要本轮存在用量元数据就强制显示，不再隐藏 0 用量
  - 模型名未获取时显示「模型:—」，缓存命中率始终显示（>0 时强调色）
  - 容错解析从多键名（input_tokens/prompt_tokens/…）深度查找
[新增] 夜间模式切换并持久化
  - 设置页「外观」单选：跟随系统 / 浅色 / 深色
  - 配置写入 SharedPreferences，应用重启后保留
[修复] 本地持久化遗漏 images 字段（此前图片重启后丢失）
[修复] 设置页保存时遗漏 themeMode（此前主题设置实际不生效）

v1.8 (versionCode 13)
----------------------------------------------------------------
[修复] 启动闪退（v1.4~v1.7 均受影响）
  - 根因：OkHttp 连接池配置 ConnectionPool(0, 0, ...) 非法，
    keepAliveDuration 必须 > 0，首次构建客户端时抛
    IllegalArgumentException，导致一打开就崩溃
  - 移除该配置；WebSocket（Connection: Upgrade）连接本身
    不会从连接池复用，无需禁用连接池

v1.7 (versionCode 12)
----------------------------------------------------------------
[新增] 崩溃日志捕获页
  - 应用崩溃后再次打开会显示崩溃堆栈，可一键复制反馈，
    不再盲猜原因
[优化] APK 体积 9.9MB → 3.4MB

    下的截断风险（截断的安装包会闪退）
[加固] Markdown 解析器异常自动降级为纯文本显示

v1.6 (versionCode 11)
----------------------------------------------------------------
[新增] 助手回复 Markdown 渲染（自研轻量解析器，零第三方依赖）
  - 标题 # ~ ######
  - 粗体 **x**、斜体 *x*、行内代码 `x`、链接 [文字](地址)
  - 围栏代码块：深色卡片 + 语言标签 + 横向滚动不折行
  - 表格：表头加粗 + 分隔线 + 单元格自动换行
  - 无序/有序列表、引用块
  - 流式输出期间未闭合的代码块也会即时渲染
[说明] 用户消息仍为纯文本气泡；长按复制不受影响

v1.5 (versionCode 10)
----------------------------------------------------------------
[修复] "错误：连接失败：Software caused connection abort"
  - v1.4 重试条件缺陷：服务端推送"思考中"状态后即视为
    "已收到内容"，连接中断时重试被跳过——恰好在最常见的
    故障场景下重试永不触发
  - 现连接类错误一律自动重试（最多 2 次），复用同一
    idempotencyKey，服务端幂等去重，消息不会重复执行
  - 重连时提示"连接中断，自动重连（第 N 次）…"并清空半截文本
[新增] WiFi 高性能锁 + CPU 唤醒锁
  - 等待回复期间持锁，防止 Android WiFi 省电模式掐断 TCP
[优化] WebSocket ping 间隔 30 秒 → 20 秒，防止 NAT 映射超时
[优化] 所有重试共享 5 分钟总超时预算，不放大等待时间
